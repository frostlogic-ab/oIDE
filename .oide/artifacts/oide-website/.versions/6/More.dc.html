How it works

oIDE directs. Your own CLI does the work.

oIDE has no model of its own and no sign-in of its own. It starts the Claude Code CLI you already installed, one process per agent, and shows you what each one is doing.

FAQ

Questions people ask first

Do I need an Anthropic API key?

No. oIDE runs the Claude Code CLI you already use, so it works with whatever that CLI is signed in to: a Claude Pro or Max plan, or an API key if you prefer one. Usage counts against that account the same way it does in your terminal.

Can oIDE see my credentials?

No. You sign in through Anthropic's own flow in the CLI. oIDE starts the CLI and reads its event stream. It does not touch tokens and it does not modify the CLI.

Is oIDE made by Anthropic?

No. oIDE is an independent open-source project that works with Claude Code. It is not affiliated with or endorsed by Anthropic.

Can I still edit files myself?

Yes. There is a file editor with tabs, search and a terminal. It is simple on purpose, because most of your time in oIDE goes into directing and reviewing agents.

How many agents can I run at once?

As many as your machine and your plan's limits allow. Settings > Agents > Max running (3 by default) queues the rest. The status bar shows session and weekly usage, so you can see how fast you are spending it.

Does it work with local models?

Yes, through the CLI's own environment variables. Add an endpoint under Settings > Models and it appears next to the built-in models. A model needs tool use to work well as an agent.
