Developer Cowork

One workspace for the plan, the agents and the review.

Writing the code is one part of shipping it. Someone has to decide what gets built, and someone has to check the result. oIDE keeps all three in one window, and your agents take part in each.

Plan

Give every agent a plan to work from.

An agent does its best work from a clear brief. In oIDE the brief sits next to the code, as designs, docs and whiteboards that you and your agents both edit. A shared backlog is next.

Artifacts

Designs, docs and whiteboards next to the code

Import artifacts from claude.ai or let an agent write one. Hand a design to an agent as its spec, and see which agents are reading or writing each artifact.

  • Open an artifact and tell its agent what to change, or pin a comment on the preview.
  • Every change is a version you can compare or restore.
Backlog · coming next

One backlog, kept by you and your agents

The project backlog is moving into oIDE. You and your agents both add items and keep them in order, and PM agents do the upkeep. When an item is ready, you start an agent on it from the list.

  • PM agents write up new items and link the design or doc that describes them.
  • You decide what goes in and what comes first.
  • Start an agent session from any item, with the item and its spec as the goal.
