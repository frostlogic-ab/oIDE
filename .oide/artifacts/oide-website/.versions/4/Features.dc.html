Nothing reaches main until you say so.

Every agent works on its own branch in its own git worktree. You review the result the way you would review a teammate's pull request.

Source control

Every project, every worktree, one screen

See what each agent changed, which branches are behind, and what is ready for review. oIDE warns you when two agents edit the same file, before it turns into a merge conflict.

Review

Comment on the diff. The agent fixes it.

Leave comments on lines and send them back as one round of feedback. The agent revises in the same worktree. When you are happy, open a pull request or merge locally.

  • The agent's own summary and the checks it ran sit next to the diff.
  • Unified or split view, with a Viewed mark per file.
Extend

Give agents better tools and better context.

An agent is only as good as what it can reach. oIDE has a marketplace of tools made for agents, and it brings your designs and docs into the project.

Marketplace

A marketplace where the customer is the agent

Extensions add tools that agents can call: inspect a database, preview the app in a browser, deploy a branch. Every extension declares what its tools do. Read-only tools just run. Tools that change things ask first.

Custom tools

Not in the marketplace? Paste the URL.

Give oIDE the address of any MCP server. It works out how to connect, how to sign in and which tools the server offers.

  • Imports the servers you already set up in other apps on this computer.
  • Switch single tools off, or make one ask first.
  • Keep it to yourself, or share it with the project through git.
Artifacts

Designs, docs and whiteboards next to the code

Import artifacts from claude.ai or let an agent write one. Hand a design to an agent as its spec, and see which agents are reading or writing each artifact.

Models

Decide where your usage goes

A preset sets which model leads and which models take the simple, standard and complex subagent tasks, each with its own effort level. Add a local or self-hosted model and it shows up in every picker.

Session and weekly usage stay in the status bar, so you see what a wall of agents costs you.
