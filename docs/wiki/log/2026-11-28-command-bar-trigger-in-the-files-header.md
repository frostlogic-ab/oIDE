## [2026-11-28] build | Command-bar trigger in the Files header

The Files header now shows the same command-bar trigger as the Wall and Focus, labelled "Search files,
run a command, or jump to a session", so quick open is one click away while browsing files. New
`ScreenDef.commandTrigger` (placeholder text) puts the trigger in a `title` header, between the title
and the scope switcher. Pages: [screen-files](../pages/screen-files.md),
[desktop-shell](../pages/desktop-shell.md).
