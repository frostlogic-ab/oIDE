# Design system

Extracted from the Mission Control canvas ([../raw/design/](../raw/design/)), direction "A · Mission Control",
chosen for all screens. Implemented as Tailwind v4 theme tokens in `packages/ui/src/tokens.css` and
shared components in `packages/ui`. Screens must match the canvas; when in doubt, open the matching
`.dc.html` file and copy its spacing, sizes and colours.

## Brand

The logo is **Signal** ([docs/brand/README.md](../../brand/README.md)): an open lowercase o with the lead
agent (mint) in its opening and a hub at its centre, on a 64-unit grid, ring gradient `#7AA2F7` → `#C4A7E7`.
In the renderer use `<Logo>` from `@oide/ui` (`variant="mark" | "wordmark"`, `size`, `tone="brand" | "mono"`,
optional `title`); at 32 px and below it draws the heavier small geometry. **The logo keeps fixed brand
colours and does not follow the user-selected accent**; `tone="mono"` draws in `currentColor`. The header
shows the mark (`<Logo size={26} />`) beside "oIDE" (Inter 700, 14px) with a "by [Frostlogic]" subtitle
underneath: `<FrostlogicLogo height={10} />` from `@oide/ui`, the company wordmark traced from Frostlogic's
vector logo (roof in Frostlogic blue `#2491EB`, the word in `currentColor`, here `ink-2`; copy in
`docs/brand/frostlogic-wordmark.svg`). Geometry lives in
`packages/ui/src/logoGeometry.ts`, generated by `tools/brand/build-brand.mjs` with every other brand file
(SVGs, app icon sources, docs site assets, social preview). Never put "Claude" or Anthropic marks in it.

## Type

- UI: Inter 400/500/600/700, base 13px. Common sizes 9.5, 10.5, 11, 11.5, 12, 12.5, 13, 14, 16, 18, 20px.
- Section labels: 11px, weight 600, `letter-spacing: 0.08em`, uppercase, `ink-3`.
- Code, paths, branches, shas: JetBrains Mono 400/500, 11-12.5px. Diff lines 12px / 20px line height.
- Line height is the font's `normal` (Inter ≈ 1.21), as on the canvas, which never sets one
  (`html { line-height: normal }` in `tokens.css` overrides Tailwind's 1.5). Multi-line copy sets its
  own leading: activity 1.6, prose 1.5, notes and hints 1.45.
- Fonts are bundled (`@fontsource/inter`, `@fontsource/jetbrains-mono`); no remote font loading (CSP).

## Shape and layout

- Radii: 3 (tiny chips), 6 (buttons, rows), 8 (inputs, cards), 10 (rail items, panels), 12 (project cards).
- App frame: header 44px (`chrome`, bottom border `line`), left rail 56px (40px square items, radius 10,
  selected = `selected` bg + accent icon), status bar 26px (11.5px `ink-3`).
- Buttons: 28px (small, 12px text) and 36px (primary, 13px text), radius 6-8, border `line-3`.
- Icons: inline stroke SVG, 18px, `stroke-width: 1.7`, round caps and joins. Never emoji.
- Status dots 6-8px circles in the status colour.
- Sidebars are resizable: every screen's left and right asides (Wall projects and artifacts, Focus
  agents and inspector, Files tree / search / activity, Review files and summary, Source control,
  Artifacts details, Marketplace categories and details, Settings sections) render through
  `ResizableAside` (`apps/desktop/src/renderer/src/components/ResizableAside.tsx`). The canvas widths
  are the defaults; each panel's min (where its content still fits) and max live in
  `src/lib/panels.ts`. The screen's main area always keeps 360px (`MAIN_MIN_WIDTH`; mains are `flex-1 min-w-[360px]`):
  drags stop there, and a narrow window shrinks sidebars to their min first. The grab edge
  is a focusable `role="separator"` on the inner border: 6px hit area on the side without a scrollbar, a 2px accent line on hover / focus / drag,
  arrows (Shift = 64px) and Home / End from the keyboard, double-click resets, Escape cancels a drag.
  Widths persist in `settings.ui.panelWidths` (bad entries are dropped on read, never resetting `ui`); Settings › Appearance › Reset sidebar widths clears them.

## Accessibility

Real `<button>`, `<a href>`, `<input>` + `<label>`; `aria-label` on icon-only buttons; `aria-current`
on the active rail item; radiogroups for segmented controls; 4.5:1 text contrast; focus rings in accent.
Every small text pair is ≥ 4.5:1: the smallest-contrast grey for text is `ink-3` (7.0:1 on a card,
6.1:1 on `selected`). Borderless text links stay underlined (a `ghost` `LinkButton` is underlined), so
they are not told apart by colour alone. Every screen works at the 1100×700 window minimum: no
clipped labels, no mid-phrase wraps, no status-bar item past the edge (container queries narrow the
Focus header, prompt and inspector).

## Tokens in code

`packages/ui/src/tokens.css` is a Tailwind v4 `@theme`. Default Tailwind colours are removed
(`--color-*: initial`), so only canvas colours exist as utilities: `bg-ground`, `bg-chrome`,
`bg-panel`, `bg-card`, `bg-raised`, `bg-selected`, `bg-selected-2` (`#1A2130`, selected preset/pill),
`border-line` … `border-line-6`, `border-line-hover` (`#4A515C`), `text-ink` … `text-ink-5`,
`text-ink-code` (`#B8BFC9`, activity lines), `text-ink-prose` (`#D5D9DF`, transcript prose),
`text-on-accent`, `bg-accent`, `text-link`, and the status families `ok*`, `warn*` (incl.
`warn-bg-2` `#221D12`, `warn-ink` `#A9A08E`, `warn-kbd` `#8A6A30`), `bad*`, `review*`, `violet*`.
Radii: `rounded-xs` 3, `rounded-sm` 6, `rounded-md` 8, `rounded-lg` 10, `rounded-xl` 12,
`rounded-2xl` 14 (dialogs), `rounded-3xl` 16 (Spawn). Frame sizes: `h-header` 44, `w-rail` 56,
`h-status` 26. Fonts: `font-sans` Inter, `font-mono` JetBrains Mono (bundled, latin 400–700 / 400–500).
The `ico` utility is the canvas `.ico` (18px, stroke 1.7, round caps). Accent switches at runtime:
`setAccent(hex)` sets `--color-accent` on `<html>` (`ACCENT_OPTIONS` holds the four choices); the
settings store applies `settings.ui.accent` automatically. Import the tokens after Tailwind:

```css
@import 'tailwindcss';
@import '@oide/ui/tokens.css';
```
